2この画面からGitHubへアップロード

選んだHTMLを、このページから直接GitHubの main ブランチへ上書き更新できます。GitHubのFine-grained personal access tokenが必要です（初回のみ発行）。

🔒 初期状態ではトークンを保存しません。「この端末に保存」を有効にした場合だけ、このブラウザの保存領域に残します。ブラウザ保存は暗号化された秘密保管庫ではありません。 公開サイトのHTMLやGitHubのファイルには絶対にトークンを書き込まないでください。共有PCでは保存しないでください。
🔑 トークン発行画面 ↗🔐 発行済みトークン管理 ↗
初回：トークンの発行設定を見る
  1. GitHubにログインして上の「トークン発行画面」を開く
  2. Token name は kakugari-updater など、Expiration は短め（例：30日）
  3. Resource owner：monjasama-ops
  4. Repository access：Only select repositories → kakugari-derby のみ
  5. Repository permissions：Contents → Read and write（MetadataのReadは自動付与）
  6. 「Generate token」で作成し、表示されたトークンをコピー。再表示できないので紛失したら再発行

必要なのは対象リポジトリのContents権限だけです。全リポジトリへのアクセス権やワークフロー権限は不要です。

現在は保存OFFです。入力したトークンは画面を閉じると消えます。

保存先はこのサイト専用のブラウザ保存領域（localStorage）です。ブラウザのデータ消去、別の端末・ブラウザ、プライベートモードでは引き継がれません。端末を使える人や、このサイトで実行されるスクリプトに読み取られる可能性があります。
